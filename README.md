# Gestor de Tareas 

## Estructura de index.html

El archivo `index.html` contiene la estructura principal de la página web del proyecto.

En primer lugar, se utiliza una etiqueta `<h1>` para mostrar el título principal de la página:

```html
<h1>Gestor de Tareas</h1>
```
A continuación, se utiliza una lista no ordenada `<ul>` para mostrar las tareas pendientes Cada tarea se incluye dentro de una etiqueta `<li>`:

```html
<ul>
    <li>Estudiar para el examen</li>
    <li>Entregar el proyecto de GitHub</li>
    <li>Hacer la compra</li>
</ul>
```
